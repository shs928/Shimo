卡片盒笔记法（Zettelkasten）

卡片盒笔记法的核心不是"收藏"，而是用固定格式改写： 把读到的内容用自己的话重述成一张原子化卡片，再通过链接让它与既有卡片对话。 笔记的价值在连接，不在数量。

本文是「读书笔记」专题的第一篇，配套实践见 渐进式总结；标签索引在 #方法论 下。

三条基本原则

  • 原子化：一张卡片只讲一件事，标题即结论
  • 自述化：必须用自己的话改写，禁止摘抄式收藏
  • 连接化：每张新卡至少与一张旧卡建立链接

卡片的固定格式

我目前的模板如下，配合拾墨的模板中心一键创建：

markdown 2026-08-14 · 32 行 
# 一句话结论（标题即卡面）

---
来源：《卡片笔记写作法》 P42
标签：#方法论 #读书笔记
---

用自己的话重述的内容，1-3 句。
